# Lantern Delve

A homework focus buddy plus a paper-style adventure game.

Latest version: **2026.11.04.1**

- [Play in your browser](https://github.com/GabeisRandom/lantern-delve/raw/main/Lantern%20Delve%20-%20play%20in%20your%20browser.html): one file. Save it, then open it in Chrome or Edge.
- [Windows app](https://github.com/GabeisRandom/lantern-delve/raw/main/Lantern%20Delve%20-%20Windows%20app.zip): unzip it and double-click "Start Lantern Delve" (needs Python 3).

Both keep themselves up to date, and only install versions signed with the maker's key.
